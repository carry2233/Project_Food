# 🪳 2D 횡스크롤 액션 게임

## 📌 1. 게임 개요
플레이어가 다양한 기술을 활용하여 길에 등장하는 바퀴벌레(적)를 처치하고,  
최종적으로 **보스 바퀴벌레를 처치하는 것**을 목표로 하는  
**2D 횡스크롤 액션 게임**이다.

---

## 🎮 2. 조작 방법
- 이동: `A / D`  
- 점프: `Space`  
- 도약: `Space 길게 누르기`  
- 난타: `M (홀드)`  
- 수리검 투척: `N`  
- 패링: `C`  

---

## 🧭 3. 게임 진행 구조
1. 메인 화면 진입  
2. 게임 시작  
3. 기술을 활용하여 적(바퀴벌레) 처치하며 진행  
4. 보스 구간 도달  
5. 보스전 진행  
6. 보스 처치 후 맵 끝 도달 시 클리어  

---

👉 **핵심 루프**  
전진 → 전투 → 기술 사용 → 적 처치 → 보스 도전 → 클리어  

---

## ⚔️ 4. 전투 시스템

### ▪ 기술 설명
- **난타**  
  → 사용 중 범위 내 적에게 지속 피해  

- **수리검 투척**  
  → 수리검을 발사하며 히트 영역 내 적에게 지속 피해  

- **패링**  
  → 적 공격 타이밍에 맞춰 히트 시 **적을 스턴 상태로 만듦**  

---

### ▪ 자원 시스템
- **체력**  
  → 0이 되면 게임 오버  

- **기력**  
  → 기술 사용 시 감소, 시간이 지나면 자동 회복  
  → 0이 되면 일정 시간 동안 기술 사용 불가  

---

### ▪ 적 구성
- **바퀴벌레**  
  → 플레이어가 일정 범위 내 접근 시 추적 시작  
  → 근접 시 공격  

- **보스 바퀴벌레**  
  → 일반 적보다 크고 체력이 높은 상위 개체  

---

## ✅ 최종 정리
- 다양한 기술을 활용한 **액션 중심 전투 시스템**  
- 자원(체력, 기력) 관리 기반의 **전략적 플레이**  
- 일반 적을 돌파하고 보스를 처치하는 **직선형 진행 구조**
